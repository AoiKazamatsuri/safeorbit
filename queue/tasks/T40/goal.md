# 智能对话：接入大模型，回答可核对

## 范围

- 要交付：
  - 后端：
    - 大模型适配器：经 Vercel AI SDK 接入用户选定的供应商，须在中国大陆可稳定访问；密钥只放本机环境变量。
    - 只读查询四种：当前状态、历史事件检索、单次出行详情、两段时间的行为比较；每个问题最多调用 3 次；大模型只收到计数、日期、事件摘要与记录编号，不收到完整轨迹坐标。
    - 先核对再送出：回答里的数字与记录编号必须出现在查询结果中，核对通过才返回，并附引用；核对不通过时说明无法给出可靠回答。
    - 用提问的语言作答；只描述行为数据及其变化，不做医学诊断；“最近”一类的模糊时间换成明确的日期范围。
    - 事件经过说明与出行规律描述改由大模型生成，失败时退回模板。
  - App：对话页改为调用接口，显示回答与引用；去掉固定回答；会话列表仍存在家属手机上。
- 不包含：服务器保存对话记录；大模型参与风险判定（规则不变）；账号与绑定；双语界面。
- 允许修改的位置：`object/server/` 下相关文件；`object/ios/` 下对话页、固定回答数据与对应测试、工程文件；具体文件清单在批准前补全。`AgentChatUI.swift` 是 T31 的交付文件，须在 T31 通过后再改。队列记录只经工具维护。

## 验收标准与验证方法

| 编号 | 可观察的结果 | 验证方法 | 通过条件 |
|---|---|---|---|
| A1 | 核对与边界有用例 | 后端单元测试，大模型用替身代替 | 数字或编号对不上时不送出；查询次数不超过 3；问到病情时说明边界 |
| A2 | 接通真实大模型 | 用三个常用问题与一个病情问题实际提问 | 回答中的日期、次数与记录可在查询结果中核对；病情问题不给诊断 |
| A3 | App 测试与编译 | 全部 iOS 测试；真机版本编译 | 无失败用例；构建成功 |
| A4 | 模拟器实跑 | 家属端新建会话，点问题标签提问并截图 | 显示大模型回答与引用；不再出现“Demo answer:” |
| A5 | 改动只在授权位置 | `git diff --stat`、`git diff --check`；提交时的队列检查 | 仅授权位置；退出码 0 |

验收安排：A1–A5 由执行者代跑，标“未独立验证”。调用大模型会产生费用，按用户确认的供应商与额度进行。真机效果由用户实测后决定是否通过。
