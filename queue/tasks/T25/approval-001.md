# 位置页“回到默认视图”长条改为右侧常驻的“定位老人”按钮

## 来源与目的

用户追问家属位置页地图上方的“Back to default view”长条：属于临时设计还是常驻设计，地图应用是否不应有这种设计。核对结果：该操作由任务 T8 加入（批准范围写明“地图手势缩放、平移后顶部出现回到默认视图操作”），T14 保留；它只在用户拖动或缩放地图后出现在屏幕上方正中，点后回到默认取景并消失（`LocationUI.swift` 的 `showingReset`）。产品设计第 5.2 节的右侧悬浮按钮只列智能体入口与新增安全区，设计稿界面 02–04 也没有这条长条。

点它实际做三件事：地图移到老人最新已知位置；恢复默认比例（街区级，老人位于底部人物卡上方）；恢复自动跟随（用户拖动或缩放后暂停跟随，以免位置更新把正在浏览的地图拉走）。这一功能需要保留；常见地图应用把它做成角落按钮组里常驻的圆形图标按钮，而不是在屏幕上方弹出文字长条。

用户决定：把上方长条改成右侧常驻的圆形“定位老人”按钮；登记后用户指示不等 T21 通过、直接开工。`LocationUI.swift`、`LocationTests.swift`、`object/ios/README.md` 是 T21 的交付文件，本任务改动后 T21 原交付指纹失效：T21 先返工，待本任务改完后按 T21 原范围重新验证并重新交付，T21 自身范围不变；两件任务的真机复测可合并进行。

## 范围

- 要交付：
  - 删去屏幕上方的“Back to default view”长条。
  - 在右侧悬浮按钮组（智能体、新增安全区）最下方加第三个圆形按钮“定位老人”，与现有按钮同一样式（`FloatingMapButton`），图标为瞄准圈（SF Symbol `scope`），常驻显示；读屏文字说明为定位老人。
  - 点击：地图移到老人最新已知位置、恢复默认比例、恢复自动跟随，作用与原长条相同。只移动地图，不重新获取位置（任务 T19：位置由系统自动更新，不设手动刷新）。尚无有效老人位置时，按钮显示为不可用。
  - 保持现有行为：拖动或缩放后暂停自动跟随；新增安全区时的初始中心规则不变（跟随时取老人位置，暂停跟随时取当前可见中心）；导航进行中整组悬浮按钮照旧隐藏。
  - 同步文档：产品设计第 5.2 节的右侧悬浮按钮加“定位老人”并写明作用，链接本任务；`object/ios/README.md` 中“改变取景后顶部可点 Back to default view”的说明改为右侧定位老人按钮。
  - 测试：新增或维护用例，覆盖按钮常驻、拖动后点击回到默认取景并恢复跟随、点击不触发取数、无位置时不可用。
- 不包含：按跟随状态切换图标样式（如实心与空心）；新增安全区页、出行详情页、老人端与导航页的地图；默认比例与首次进入缩放（T21）；地图服务、配色与其他布局；不新增依赖。
- 允许修改的位置：`object/ios/SafeOrbit/LocationUI.swift`；`object/ios/SafeOrbitTests/LocationTests.swift`；`object/ios/SafeOrbit/Localizable.xcstrings`（仅新按钮的文字及删去不再使用的旧文字）；`truth/产品设计.md`（仅第 5.2 节右侧悬浮按钮一句）；`object/ios/README.md`（仅上述一处说明）。队列记录只经工具维护。
