# 出行详情地图、十月演示轨迹与带手机边框录屏

## 范围

- 要交付：详情地图上边两角沿用 Data 页样式；家标复用首页的房屋标记和青绿色；回家起终点共址时避免两个图标堆叠。改进历史演示步行采样，地理路线保持沿街，去返、步速和途中停顿有自然差异。保留原数据库，仅向隔离的本机演示库回放十月数据。从当前源码构建并在 iPhone 18 Pro 模拟器用家属演示入口录制 Records、Data、一次出行的地图及时间线、返回、Trend，加机身边框输出 MP4。
- 不包含：原数据库写入或重置、真实路线或风险算法改动、真机安装、云服务部署、发布视频、重新设计首页。
- 允许修改的位置：object/ios/SafeOrbit/RecordsUI.swift、LocationUI.swift（标记视图共用）及相应现有 iOS 测试，object/dev/history.mjs、history.test.mjs（历史步行生成及验证）。本机隔离环境、日志和视频保存在 Git 工作树以外；队列只由工具维护。
