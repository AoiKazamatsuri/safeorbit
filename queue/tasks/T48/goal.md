# 落地阶段总任务：内部测试可用

## 范围

- 要交付：
  - 五件子任务，按顺序进行：
    1. 云端部署（T49）。
    2. 家庭与邀请加入（T50，依赖 T36）。
    3. 安装发布与正式推送（T51）。
    4. 老人手机后台可靠性（T52）。
    5. 试运行与阈值校准（T53）。
  - 本件自己的集成交付：五件子任务全部通过后，写内部测试说明（安装、加入家庭、授权、出门测试、反馈问题、退出测试），放在新文件 `object/dev/internal-testing.md`；组织测试团队按落地阶段“完成的判断”的规模在室外实测，逐项核对并汇总测试记录；实测发现的问题按根契约第 16 条一次修完。
  - 需要用户本人办理的事（越早越好）：付费苹果开发者账号与推送密钥（T51 需要）；云服务器与域名，以及国内服务器所需的备案（T49 需要）；高德地图密钥的使用额度；内部测试者名单（须为开发者团队成员）；各子任务与本件的真机验收。
- 不包含：落地阶段“暂不做”所列各项；Demo 阶段的录制与 T36 的范围；T44 真实路线学习。
- 允许修改的位置：本件集成阶段只改实测修正所需的 `object/ios/`、`object/server/`、`object/dev/` 下文件，以及新文件 `object/dev/internal-testing.md`；不改 truth，确需修改时先停下问用户。各子任务的可写范围写在各自任务里。队列记录只经工具维护。

## 验收标准与验证方法

| 编号 | 可观察的结果 | 验证方法 | 通过条件 |
|---|---|---|---|
| A1 | 五件子任务全部通过 | `task status` | T49–T53 均为“通过” |
| A2 | 自动化检查全绿 | 在 `object/server/` 运行 `npm run check`；按 `gate/checks.md` 的 iOS 检查命令跑全套；`-sdk iphoneos`、`CODE_SIGNING_ALLOWED=NO` 构建；制图检查 | 全部退出码 0，无失败用例 |
| A3 | 室外实测 | 测试团队按测试说明，在落地阶段“完成的判断”规定的户数与天数内实际使用；执行者汇总每户每天的上报、提醒、导航、耗电与问题记录 | “完成的判断”各项都有实测记录；发现的问题已修复并复测 |
| A4 | 测试说明可用 | 一位未参与开发的测试者只按 `object/dev/internal-testing.md` 从零安装、加入家庭并完成一次出门测试 | 不需要开发者协助即可完成 |
| A5 | 改动只在授权位置 | `git diff --stat`、`git diff --check`；提交时的队列检查 | 仅授权位置；退出码 0 |

验收安排：A1、A2、A5 由执行者代跑，附原样命令、退出码与输出摘录，标“未独立验证”；A3、A4 由测试团队实际使用，执行者汇总记录。是否达到内部测试可用由用户决定。
