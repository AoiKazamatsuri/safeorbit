# 家属登录、老人档案与绑定前端

## 来源与目的

用户先要求开发家属登录、建立老人档案和绑定页面，随后明确收窄为“现在只需要开发前端”，最新要求全部 UI 使用英文、去除不必要文字说明；进一步指定仅隐藏手机号输入框小标题，Continue 与 Save profile 使用最大圆角，档案页去掉 Preferred name 和 Time zone。本轮只交付 iPhone SwiftUI 页面和前端交互；最新英文要求优先于此前产品文档的双语默认，本轮不改 truth 正本，视觉依据仍为 reference/ui/，产品流程依据 truth/产品设计.md。

## 范围

- 要交付：身份选择、家属 Apple 登录页、手机号页、老人档案表单（姓名、照片、手机号；不展示称呼和时区输入，称呼默认使用姓名，时区沿用设备默认）、家属二维码页、老人扫码与绑定结果页；输入校验、照片选择、相机权限、加载/失败/过期状态、统一英文与精简文案、前端接口调用与会话保存；Xcode 页面预览与测试。
- 不包含：后端程序、数据库、业务接口实现与联调成功；安全区、地图出行、推送、风险与智能对话；不修改 truth 或 reference，不添加生产假登录或演示模式。
- 允许修改的位置：object/ios/；object/dev/generate-ios.mjs、object/dev/README.md（工程文件清单与前端使用说明）。此前刚新增的后端代码全部撤回，已有环境骨架保持原样。
- 后端接口目前未实现，页面在真实请求失败时显示可重试提示，不宣称登录或绑定已成功。测试数据只放测试与 Xcode 预览。
