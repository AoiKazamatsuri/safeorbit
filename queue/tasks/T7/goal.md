# 家属登录、老人档案与绑定前端

## 范围

- 要交付：统一白底、居中青绿标题、细边框胶囊输入、浅绿第三方按钮与青绿主按钮；身份选择、邮箱登录/邮箱注册/密码找回与 Google 登录前端入口、家属 Apple 登录页、手机号页、老人档案表单（姓名、照片、手机号；不展示称呼和时区输入，称呼默认使用姓名，时区沿用设备默认）、家属二维码页、老人扫码与绑定结果页；输入校验、照片选择、相机权限、加载/失败/过期状态、统一英文与精简文案、国家区号选择和本地手机号输入（China +86 默认；China、Hong Kong、Macau、Taiwan、United States、United Kingdom、Japan、Singapore、Australia；无效输入红字）、Apple 登录入口兼容准备失败后的重试；Google 通过服务端授权 URL 与系统网页授权回调，邮箱登录注册找回使用未实现的服务接口，不假登录、前端接口调用与会话保存；Xcode 页面预览与测试。
- 不包含：后端程序、数据库、业务接口实现与联调成功；安全区、地图出行、推送、风险与智能对话；不修改 truth 或 reference，不添加生产假登录或演示模式。
- 允许修改的位置：object/ios/；object/dev/generate-ios.mjs、object/dev/README.md（工程文件清单与前端使用说明）。此前刚新增的后端代码全部撤回，已有环境骨架保持原样。
- 后端接口目前未实现，页面在真实请求失败时显示可重试提示，不宣称登录或绑定已成功。测试数据只放测试与 Xcode 预览。

## 验收标准与验证方法

| 编号 | 可观察的结果 | 验证方法 | 通过条件 |
|---|---|---|---|
| A1 | 三组页面及身份选择支持统一英文与精简文案与现有视觉风格 | 模拟器构建、Xcode 预览、页面渲染截图检查 | 可构建，布局可读，参考指向不变，登录/注册无顶部 App icon 或 SafeOrbit、无访客入口；现有身份/电话/档案/二维码/扫码/结果页风格统一 |
| A2 | 档案表单有字段校验和照片选择，不展示称呼与时区输入 | 前端模型测试、预览检查 | 无效输入红字且不能提交，空输入无红字；区号自动组合，切换保留号码，既有号码回填；照片缩放后上传，保存失败保留表单 |
| A3 | 绑定码可生成二维码并能严格解析，扫码有权限与失败状态 | 二维码解析与请求测试、模拟器构建 | 拒绝无关链接、过期码有刷新入口，扫码失败可重试 |
| A4 | 网络调用与会话恢复可测试，不以假数据充当生产登录 | URLProtocol 请求/错误测试，源代码检查 | 正确处理响应、401、断网与未实现接口；会话使用 Keychain |
| A5 | 所有后端新增内容已撤回，已有内容未被误改 | git diff 与范围核对 | 无 object/server 改动，已有 truth 改动保留 |

验收安排：执行者代跑构建与测试，记录原样命令、退出码和输出摘录，标未独立验证；用户验收。Apple 真机签名、实际登录和两机绑定留到后端就绪后的联调任务。
