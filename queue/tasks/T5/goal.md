# 队列规则补“请求号不复用”

## 范围

- 要交付：`queue/AGENTS.md`“一致性”一节补一句：请求号一笔操作一个；重试沿用原号，新操作用新号；同一任务同一种操作再做一次（释放后再领、返工后再交付、换会话接手）也是新操作；按“编号-操作-日期”取号时，同日再做同种操作须加区分标记（如会话或轮次）。
- 不包含：修改队列工具、队列用法 `tool/queue-usage.md` 的示例或 gate 测试；根契约第 4.6 节。
- 允许修改的位置：`queue/AGENTS.md`。
