# 修复真机回家导航语言与地图路线样式

## 范围

- 要交付：真机步行请求采用已验证有效的高德简体中文设置，SDK 请求在整个生命周期内保持适用于境内步行规划的设置，保留既有步行路径几何和方向。地图视图单独使用英文模式。用可靠的转向动作与距离生成英文屏幕指引和播报，未识别动作保守提示沿实际路线行走。仅在实际有路线时提示跟随路线。
- 老人地图路线按用户确认的模拟器导航样式画蓝色实线与白色描边，保留蓝色定位点、家图标、指引卡和底部操作。复用既有蓝线白边的两层画法。
- 不包含：服务端、家庭数据、地图账号或 Key 改动，新依赖，家属导航呈现改版，业务设计文档改动，向高德提交工单。
- 允许修改的位置：object/ios/SafeOrbit/{AMapRuntime,AMapWalkingRouteProvider,WalkingNavigation,ElderHomeUI,AMapCanvas,SafeZoneSelectionMap}.swift 和 object/ios/SafeOrbitTests/LocationTests.swift，限上述实现及回归验证。任务记录只经队列工具维护。

## 验收标准与验证方法

| 编号 | 可观察的结果 | 验证方法 | 通过条件 |
| --- | --- | --- | --- |
| A1 | 真机正常 Go Home | 使用现有签名和 Key 构建、安装到用户 iPhone 后，点 Go Home | 收到有效实际路线，地图上可见，显示英文指引以及距离和预计时长，不再出现 1012 |
| A2 | 英文转向与路线样式符合要求 | 核对设计稿和实际页面，并用回归测试核对转向、未知动作及路线样式 | 英文与实际转向一致，不凭空给方向；蓝色实线及白色描边沿路线绘制 |
| A3 | 既有项目检查通过 | 运行 sh object/dev/ios-check.sh 全套，git diff --check，队列暂存检查 | 退出码 0，差异范围正确 |

执行者代跑验证并写回执，标未独立验证；用户决定最终验收。
