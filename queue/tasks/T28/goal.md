# 子代理推理等级统一为 High

## 范围

- 要交付：根契约第 21 条——表中“判断、架构或高风险决策的评审”一行去掉“最高推理档”；表后说明补一句：子代理的推理等级统一用 High，不分任务形态，也不随派发它的会话自身的档位；Claude Code 派发时把 Agent 工具的推理等级设为 high，Codex 用对应的 high 档。
- 不包含：模型型号的选派（仍按第 21 条表格）；已经派出、正在运行的 T27 施工子代理（不中途重派）；本机 Claude Code 全局设置；其他条款。
- 允许修改的位置：`AGENTS.md`（仅第 21 条）。队列记录只经工具维护。
