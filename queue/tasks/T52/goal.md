# 老人手机后台可靠性：省电定位、自动恢复与监测受限

## 范围

- 要交付（提纲）：
  - 在家用低功耗方式（显著位置变化、家的区域监测），离家后提高精度；按工程架构第 8 节的上传间隔批量上报。
  - App 被关闭或手机重启后，经显著位置变化或区域监测自动恢复上报。
  - 监测受限：出行途中长时间没有有效位置，或定位、精确位置权限被关闭时，挂“监测受限”并通知家属，同一次出行只推一次；不当作风险，也不据此解除风险（产品设计第 3.3、5.9 节）。
  - 锁屏与后台时自动开始语音回家导航；做不到时后备通知照旧。
  - 耗电的测量方法与记录格式。
- 不包含：长时间停留、来回折返；真实路线学习（T44）；阈值调整（T53）。
- 允许修改的位置：`object/ios/` 的定位、导航与相关文件；`object/server/` 的风险规则、触达网关与相关测试；具体清单在批准前补全。队列记录只经工具维护。

## 验收标准与验证方法

| 编号 | 可观察的结果 | 验证方法 | 通过条件 |
|---|---|---|---|
| A1 | 锁屏持续上报 | 真机锁屏放口袋，室外出行至少 1 小时 | 家属端位置与轨迹连续，无超过约定间隔的空档 |
| A2 | 自动恢复 | 从多任务界面划掉 App；重启手机；随后出门 | 离家后自动恢复上报，家属端看到位置 |
| A3 | 监测受限 | 出行途中关闭定位、关闭精确位置、开飞行模式；后端用例 | 家属收到一次“监测受限”通知；风险等级不因此改变 |
| A4 | 锁屏自动导航 | 真机锁屏时触发低风险 | 自动开始语音导航，或后备通知出现并可一点开始 |
| A5 | 耗电记录 | 真机全天使用 | 按约定格式记录耗电，写进回执 |
| A6 | 检查与范围 | `npm run check`；iOS 全套测试；真机版本构建；`git diff --stat`、`git diff --check`；提交时的队列检查 | 退出码 0，无失败用例；仅授权位置 |

验收安排：执行者代跑终端检查，标“未独立验证”；真机各项由用户或测试团队核对。最终由用户验收。
