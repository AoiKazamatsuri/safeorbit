# 家属地图轨迹、布局与安全区编辑返工

## 来源与目的

用户要求修正放大后轨迹偏离道路、老人箭头和风险气泡位置、安全区半径与底部卡片及头像布局，并明确批准按 `reference/ui/06-add-safe-zone@2x.png` 新增与编辑安全区。新建半径默认为 200 米；编辑只在当前 App 会话有效，正式会话也可操作，不接尚不存在的后端写接口。

## 范围

- 要交付：Debug 演示轨迹沿南京大学周边地图道路转折；正式数据稀疏时只显示真实点，不把直线或推算路线当实际轨迹；默认镜头使老人箭头水平居中、位于人物卡上方可见区域中央，风险气泡锚在箭头上方；保留手动缩放、拖动、复位和刷新不抢镜头；Campus 演示安全区半径改为 200 米，地图圆圈按各区实际半径绘制；按 06 参考图新增和编辑安全区页面，地图准星选点，标签兼名称，支持 Home、Market、Hospital、自定义标签，100、200、500、1000、2000 米档位，地址不可用时显示坐标，可新增、修改、删除，改动只在当前会话有效并在界面说明；略缩老人信息白卡、头像下移约 18 pt，保持底部三按钮栏和触控区域。
- 不包含：后端安全区写接口、跨会话或跨设备同步、客户端风险判定、地图道路匹配服务、truth 与 reference 修改；不纳入现有两份 `.xcstrings` 改动。
- 允许修改的位置：object/ios/ 下 Location SwiftUI、位置展示模型、预览数据、相关测试、前端说明和视觉核对记录；必要时工程文件及 object/dev/generate-ios.mjs；队列记录只经队列工具维护。
