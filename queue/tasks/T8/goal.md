# 家属端 Location 首页与应用内步行导航第一版

## 范围

- 要交付：家属绑定后的首页路由；实时位置、朝向、轨迹、安全区、状态、人物卡的地图显示；共用 Location/Agent/Records 底栏及两个简洁空状态；应用内 MapKit 步行路线、距离、时间、步骤和结束操作；位置权限、过期和错误状态；有号码时系统拨号；英文界面、预览和测试。
- 不包含：设置页、安全区创建、事件详情、风险状态、语音导航、自动转向推进、偏离重算、后端业务实现、生产演示数据、提交或推送。
- 允许修改的位置：object/ios/ 下 SwiftUI 源码、工程配置、测试、预览与说明；object/dev/generate-ios.mjs；由队列工具维护的 .shell/queue/ 和 queue/tasks/。不修改 truth/ 或 reference/ui/。

## 验收标准与验证方法

| 编号 | 可观察的结果 | 验证方法 | 通过条件 |
|---|---|---|---|
| A1 | 已绑定家属到定位页，未完成流程不跳过 | 模拟会话测试 | 各状态路由正确 |
| A2 | 首页符合参考布局且真实数据绘图，缺数据空状态 | SwiftUI 预览、模拟器截图及模型测试 | 图标/卡片/导航显示，运行态不注入假数据 |
| A3 | 底栏共用，智能体快捷入口可切换 | 模拟器操作及测试 | 三页切换可达 |
| A4 | 导航权限、有效与无效目的地、成功及失败路线 | 服务替身测试与模拟器检查 | 不显示伪路线，距离、时间、步骤正确 |
| A5 | 刷新失败保留数据、电话只对有效号码启用 | 数据状态测试 | 错误可见，旧数据不丢失 |
| A6 | 工程可构建、测试通过，尺寸与大字可用 | xcodebuild 模拟器测试及截图 | 无编译和测试失败 |

验收安排：执行者自验并记录原样命令、退出码与输出摘录，标注未独立验证；真机定位、拨号、步行路测由用户后续验收。
