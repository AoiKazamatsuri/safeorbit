# 家属地图与 Apple MapKit 安全区选点

## 范围

本轮最新配色要求覆盖此前安全区统一蓝色的要求：所有地图的安全区标识、编辑定位针及表示区域的圆形恢复原OrbitStyle.teal绿色主题色；老人轨迹保留systemBlue蓝色虚线，当前位置和导航配色不变。只改相关配色，不改布局、交互及此前已确认功能；新增证据允许放object/ios/Verification/T12/safe-zone-green。完整iOS测试、Release与队列检查的命令及结果记回执，标注未独立验证；不自动Git提交、推送或验收。


本轮依据用户完整确认方案及地图统一蓝色补充：所有地图安全区图标和范围圆、老人轨迹、导航路线及相关标识统一systemBlue，与老人当前位置相同；共用颜色定义在CaregiverChrome.swift。安全区地图顶部28点实际圆角裁切，白色编辑卡20点，下缘与首页胶囊导航栏同一安全区域基准，地图铺底且通过实测编辑卡高度预留地图署名空间；App自有页面和抽屉立即切换，底层交互和辅助功能隔离，保留草稿滚动。 本轮不自动Git提交、推送或验收；新普通与小屏大字证据允许共用object/ios/Verification/T12/ui-blue，核对完整iOS测试、Release构建及队列检查，原样命令和读数记回执，未独立验证。


- 要交付：保留家属地图轨迹、风险文字与老人箭头的坐标锚定、老人卡片、安全区圆心标记及会话级增删改。安全区编辑改用系统 Apple MapKit，保留自定义可拖动定位针、独立地图平移缩放、按米半径圈、较矮绿色顶栏与顶部圆角、仅白卡背景阴影和端点收口的半径控件。地图边界使用现有大陆坐标转换，保存 WGS-84 坐标；拖针完成后同步圆心与地址。地址优先请求英文门牌、道路、街区和城市，无可用结果时显示准确坐标；底图标签由 Apple 地图数据与系统语言决定，不承诺国内所有道路均为英文。地图加载失败时显示原因并禁止保存，保留地图署名。移除 MapTilerSDK 2.1.3 包引用、解析文件、API Key 构建项、Info.plist 项、示例配置和说明中的密钥要求，同步工程生成器；清除本机临时 x86_64 排除项，不触碰其他本机设置。
- 不包含：后端写接口、跨会话同步、账号证书、付费服务、首页与出行详情地图重写、truth/reference 改动、推送。
- 允许修改的位置：object/ios/ 下安全区地图与编辑页、坐标适配、相关测试、字符串、Xcode 工程与配置、README 和 Verification/T8；object/dev/generate-ios.mjs；本机忽略配置只移除本轮临时架构绕行；队列记录只经工具维护。

## 验收标准与验证方法

| 编号 | 可观察结果 | 验证方法 | 通过条件 |

| A1 | 不配置第三方密钥也能构建并显示安全区编辑地图 | 普通 Debug 和 Release 模拟器构建、Xcode Build、模拟器截图 | 不需要 MapTilerSDK、密钥或排除 x86_64 |
| A2 | 拖针与地图手势独立且坐标精确 | 模拟器拖针、平移缩放、保存后重新进入；坐标与圈测试 | 拖针更新圆心和地址，平移缩放不改变所选坐标，保存沿用 WGS-84 |
| A3 | 页面、控件与失败处理保持有效 | 编辑页与小屏大字截图、加载失败检查 | 顶部绿色、地图到底部、署名可见、原卡片控件不回退；失败不保存错误位置 |
| A4 | 原前端行为继续通过 | 完整 iOS 测试、Release 构建、队列暂存检查 | 无测试失败，命令/退出码/原样输出与截图进回执 |
