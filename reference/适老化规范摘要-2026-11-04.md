## 外部要求的转述

| 来源与条目 | 要点 |
| --- | --- |
| S1，1.1–1.4 | 建议无衬线字体并支持调节；主要文字至少 18 dp/pt，最大至少 30 dp/pt。段内行距至少 1.3 倍，段间至少为行距的 1.3 倍。一般对比度至少 4.5:1，大于 18 dp/pt 的文字可为 3:1；信息不能只靠颜色传达。 |
| S1，2.1–2.4 | 内嵌适老界面的主要点击区域至少 60×60 dp/pt；独立适老 App 首页为 48×48，不能混用。其他页主要组件及弹窗关闭至少 44×44；关闭位于左上、右上或中央底部。手势需反馈，避免复杂多指手势；非必要限时应去掉。 |
| S1，4.1、5.1 | 功能应兼容系统辅助工具；适老界面不得加入广告及诱导按键。 |
| S2，Vision | 建议文字能放大至默认的至少 200%；音频提示配合可见提示，不能只依赖一种感官。 |
| S2，Mobility、Cognitive | 点击区域与间距都要足够；常用操作用简单手势并提供可见替代入口；保持操作一致，少用定时消失的内容。 |
| S3，Ensuring legibility、Using system fonts | 避免过细字重；系统字体与文字样式有助于保持层次，并随系统字号调整。 |
| S3，Supporting Dynamic Type | 检查全部字号；重要图标随文字调整；避免裁字，文字可增行，横排可改竖排，保持信息优先顺序。 |
| S4，Visual hierarchy、Adaptability、Guides and safe areas | 相关内容分组，重要内容先展示；按可用空间调整布局，适应宽高与字号变化，避开系统遮挡；多设备验证。 |

## 采用时须区分的事项

- SafeOrbit 是一个 App 中的两种身份。把老人端按“内嵌适老界面”的 60 点标准设计，是本项目拟采用的解释；不把整个 App 视为独立适老 App 来套用 48 点首页标准。
- 默认正文 20 点、标题 24 点、最低 18 点、支持至 AX5（系统辅助功能最大字号）、相邻主要按钮留 12 点、首页只保留两项主要行动，均为项目候选值或已有设计的延续；这些组合不是规范原句。
- 系统电话确认界面、系统提示及第三方地图底图文字不由本任务控制；自绘地图标记、按钮与卡片属于本任务核对范围。系统“辅助访问”模式明确不在 T32 范围内，不据 S2 的相关建议扩大任务。
